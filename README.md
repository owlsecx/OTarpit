## 📌 Overview

OTarpit is an offline-first OwlSec tool for TCP Tarpit / Sticky Honeypot. It provides an interactive cyan terminal UI and a full CLI with multi-format export (TXT, Markdown, JSON, CSV, SARIF), designed for authorized security work on Linux.

---

## ✨ Features

- TCP tarpit / sticky honeypot for slowing unwanted scanners
- Configurable sticky behavior for lab deception
- Operator controls suited to authorized honeynet use
- Logging-friendly status views
- Complements detection and diversion strategies
- Simple CLI lifecycle for start/monitor workflows

---

## ⚙️ Requirements

- **Linux**
- **Go 1.21+** (stdlib only; `CGO_ENABLED=0`)

---

## 🚀 Usage

```bash
go build -ldflags="-s -w" -o OTarpit OTarpit.go
./OTarpit --help
./OTarpit --listen 0.0.0.0:2222
./OTarpit --listen 127.0.0.1:2222 --format json
./OTarpit --help
```
